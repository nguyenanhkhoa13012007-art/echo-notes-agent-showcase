# Echo Notes — Audio & Video Agent Showcase

A bilingual Vietnamese / Simplified Chinese static showcase for an audio and video transcription agent.

- The walkthrough and chat replies are scripted mock content.
- This website does not upload files, call APIs, or connect to Hermes or Feishu/Lark.
- It contains no API credentials or private chat data.
- Real end-to-end transcription has not yet been verified; the page says so explicitly.

## Publish
